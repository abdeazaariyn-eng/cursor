# Products, Offers, And Copy

All products use the same offer ladder:

- 1 piece: `19 KWD`
- 2 pieces: `27 KWD`
- 3 pieces: `33 KWD`

Show 3 pieces as default recommended when possible. Use 2 pieces as the most emotionally easy choice for mothers who want one at home and one in the diaper bag/car/gift.

`عرض خاص بعد تأكيد طلبك`

`أضيفي [منتج مكمل] الآن بسعر 9 KWD فقط مع نفس الطلب. هذا العرض يظهر مرة واحدة فقط.`

Buttons:

- `أضيفيه لطلبي`
- `لا شكرا، كملي الطلب`

Rules:

- Only one discounted upsell item.
- It must be a different product from the main cart when possible.
- Price is always `9 KWD`.
- If accepted, update order total before final confirmation and send final order payload.
